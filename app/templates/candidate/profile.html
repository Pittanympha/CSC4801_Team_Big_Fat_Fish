How scoring works

For each job, the platform compares your normalized skill set with the job's required skills.

score = floor(100 × |your skills ∩ required| ÷ |required|)

If a job lists no required skills, every candidate scores 100. Resume text is never an input.

  • Python + SQL vs Python, SQL → 100
  • Python vs Python, SQL → 50
  • Rust vs Python, SQL → 0
